# Unreal Engine 101 – Zenva Course Project

## Overview

This repository contains my completed project and coursework from the **Unreal Engine 101 – 3D Game Creation** course by Zenva Academy. The project serves as an introduction to Unreal Engine and demonstrates the core concepts required to begin developing 3D games using Unreal Engine 5 and the Blueprint Visual Scripting system.

## Learning Objectives

Throughout this project I explored:

* Unreal Editor fundamentals
* Level creation and scene organization
* Actor placement and transformation
* Materials and lighting
* Physics simulation
* Blueprint Visual Scripting
* Variables, operators, and conditional logic
* Events and components
* Basic gameplay mechanics

## Technologies Used

* Unreal Engine 5
* Blueprint Visual Scripting
* Git
* GitHub

## Repository Structure

```text
Config/          Project configuration files
Content/         Game assets, Blueprints, maps, and materials
Source/          C++ source files (if applicable)
*.uproject       Unreal project file
```

## Running the Project

1. Clone this repository.
2. Open the `.uproject` file with Unreal Engine 5.
3. Allow Unreal Engine to generate any missing project files.
4. Press **Play** in the editor to launch the project.

## Purpose

This repository is intended as a learning portfolio and demonstrates my understanding of Unreal Engine fundamentals, editor workflows, and Blueprint programming through the completion of the Zenva Unreal Engine 101 course. The course covers editor navigation, scene creation, physics, lighting, and introductory Blueprint scripting as the foundation for more advanced Unreal Engine development.
